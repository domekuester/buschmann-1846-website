# Buschmann SEO and Accessibility

For every public page inspect title, description, lang, H1 and heading order, canonical, hreflang/x-default, Open Graph, Twitter Card, JSON-LD, sitemap, robots, internal links, alt text, address and hours. Do not blindly replace preview URLs before the final IONOS domain switch is approved.

Test landmarks, skip link, Tab/Shift+Tab/Enter/Space/Escape, visible focus, 44×44 touch targets, menu focus trap/return, `aria-expanded`/`aria-controls`, contrast, 200% zoom, reduced motion and core content without JavaScript. Prefer semantic HTML over redundant ARIA.

Record browser/tool method and evidence using the standard eight-field finding format. This is technical review, not legal advice.

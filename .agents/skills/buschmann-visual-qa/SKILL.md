# Buschmann Visual QA

Inspect header, hero, type, colours, rhythm, spacing, image composition/crops/quality, transitions, footer, legal pages and premium effect. Scroll every page fully and capture reproducible evidence.

Classify P0 broken/blocking; P1 visibly unprofessional; P2 clear polish; P3 taste. Fix P0/P1 only after reports; fix P2 only for unambiguous gain; document P3.

Every finding contains: `Severity`, `Page`, `Viewport`, `Element`, `Observed`, `Expected`, `Evidence`, `Recommended fix`. Store screenshots only under `audit/buschmann-final/screenshots/`.

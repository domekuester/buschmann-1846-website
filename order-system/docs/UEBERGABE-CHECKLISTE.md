# Übergabe-Checkliste

Zum gemeinsamen Durchgehen bei der Übergabe — Betrieb und Betreuung
nebeneinander am selben Bildschirm.

Erst abhaken, wenn es einmal gemeinsam gesehen wurde. Ein Haken, weil „das
wird schon stimmen", ist der Haken, der später fehlt.

---

## Zugang

- [ ] Adresse des Bestellsystems ist bekannt und als Lesezeichen gespeichert
- [ ] Admin-Anmeldung funktioniert — einmal gemeinsam angemeldet
- [ ] Passwort ist sicher notiert und **nicht** auf einem Zettel am Bildschirm
- [ ] Es ist besprochen, wer im Betrieb Zugang bekommt und wer nicht
- [ ] Es ist besprochen, was bei vergessenem Passwort zu tun ist

## Sortiment

- [ ] Alle Produkte, die online bestellbar sein sollen, sind vorhanden
- [ ] Einheiten stimmen (Stück, Blech, Torte)
- [ ] Produkte, die **nicht** online bestellbar sein sollen, stehen auf
      „ab …" oder „Auf Anfrage" — oder sind abgeschaltet

## Preise

- [ ] Gastronomiepreise Zeile für Zeile geprüft
- [ ] Privatpreise Zeile für Zeile geprüft
- [ ] Jeder Strich (—) in einer Preisspalte ist gewollt und wurde besprochen
- [ ] Es ist klar, an wen eine Preisänderung gemeldet wird

## Kunden

- [ ] Alle Kunden, die bestellen sollen, sind angelegt
- [ ] Namen und Lieferadressen stimmen
- [ ] **Jeder** Kunde hat eine Preisgruppe — der Hinweis oben auf der
      Kundenseite steht auf null
- [ ] Jeder Kunde hat seine Kennung und PIN erhalten
- [ ] Es ist klar, an wen ein neuer Kunde gemeldet wird

## Bestellregeln

- [ ] Bestelltage sind eingestellt und entsprechen den tatsächlichen Backtagen
- [ ] Bestellschluss ist besprochen — mit oder ohne, und wenn ja, wann genau
- [ ] Der Beispielsatz auf der Regelseite wurde gemeinsam gelesen
- [ ] Es ist klar, dass eine Änderung sofort für alle Kunden gilt

## Zahlungswege

- [ ] Es ist besprochen, welche Zahlungswege im Betrieb vorkommen
- [ ] Es ist klar, dass „bezahlt" und „abgeschlossen" getrennt geführt werden
- [ ] Es ist klar, dass das System **keine** Kasse und **keine** Buchhaltung ist
- [ ] Es ist besprochen, wer die Zahlungen nachträgt und wann

## Täglicher Ablauf

- [ ] Dashboard gemeinsam angesehen, jede Kennzahl einmal erklärt
- [ ] Eine Bestellung gemeinsam durchgeschaltet:
      Bestätigen → Produktion starten → Abschließen
- [ ] Eine Zahlung gemeinsam nachgetragen
- [ ] Eine Bestellung gemeinsam storniert (und danach wieder besprochen,
      dass sie sichtbar bleibt)
- [ ] **Produktionsliste** gezeigt und einmal gedruckt
- [ ] **Abholliste** gezeigt und einmal gedruckt
- [ ] Der Unterschied zwischen beiden Listen ist klar

## Kundenseite

- [ ] Die Bestellseite eines Kunden wurde einmal gezeigt
- [ ] Eine Testbestellung wurde aufgegeben und ist im Dashboard angekommen
- [ ] Die Testbestellung wurde anschließend storniert

## Herstellkosten und Marge

- [ ] Es ist klar, dass Herstellkosten **freiwillig** sind
- [ ] Es ist klar, dass Kunden diese Zahlen **niemals** sehen
- [ ] „Kostenbasis unvollständig" wurde einmal gezeigt und erklärt
- [ ] Es ist besprochen, ob und wann Herstellkosten gepflegt werden

## Daten und Sicherung

- [ ] Es ist erklärt, dass Bestellungen dauerhaft gespeichert bleiben
- [ ] Es ist erklärt, dass historische Preise historisch bleiben
- [ ] Es ist erklärt, **wer** die Datensicherung durchführt und **wie oft**
- [ ] Es ist erklärt, was im Fall einer Wiederherstellung passiert und
      wie lange das ungefähr dauert
- [ ] Es ist besprochen, dass das System keine E-Mails verschickt und keine
      Daten an Dritte weitergibt

## Unterlagen

- [ ] **Betreiber-Handbuch** übergeben
- [ ] **Erste Schritte** übergeben
- [ ] Beides liegt an einer Stelle, die im Betrieb wiedergefunden wird

## Ansprechpartner

- [ ] Telefonnummer / E-Mail: ______________________
- [ ] Erreichbarkeit ist besprochen (Zeiten, Wochenende)
- [ ] Es ist besprochen, was ein dringender Fall ist und was bis morgen Zeit hat
